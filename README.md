# تطبيق التجويد
1. افتح المجلد في Android Studio (Koala أو أحدث) مع JDK 17 ثم اضغط Sync.
2. شغّل على جهاز أو محاكي (Android 7.0 فأعلى).
3. الصوت من everyayah.com (Husary_64kbps) ويحتاج إنترنت أو تحميلًا مسبقًا من تبويب المصحف > التحميل.
4. المصحف الكامل: من تبويب المصحف > المصحف اختر "تحميل كل السور" و"تحميل الخط العثماني". المصدر الافتراضي api.quran.com (واجهة قديمة غير موثقة حاليًا)، ويمكن تغييره أو استيراد ملف JSON فيه verse_key و text_uthmani_tajweed.
5. روابط الفيديو في videoList داخل Extras.kt، ونصوص الدروس في lessonText.
